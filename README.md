# 🎨 3D Portfolio Experiment — Interactive Virtual Roo

An experimental 3D portfolio concept built with pure **HTML, CSS, and JavaScript**, featuring an interactive 3D room where certificates are displayed on the walls. This project explores creative interfaces, immersive experiences, and advanced 3D CSS transformations.

## 🌟 Features

- **🏠 Fully Interactive 3D Room**  
  Built entirely with CSS 3D transforms — rotate, explore, and move through the space.

- **📜 Certificate Wall Gallery**  
  Certificates displayed as framed wall elements with smooth hover effects.

- **🎬 Smooth Cinematic Animations**  
  Door opening, camera transitions, and room movement.

- **📱 Responsive & Touch-Friendly**  
  Optimized for both desktop and mobile interactions.

- **⌨️ Keyboard Support**  
  `+` / `-` for zoom, `0` to reset, `Enter` for the door, `Esc` for modals.

- **🔍 Clean Modal Viewer**  
  View any certificate in full-size modal format.

- **🎵 Ambient Sound Effects**  
  Optional sounds for a more immersive experience.

## 🛠️ Technologies Used

- **HTML5** — structure  
- **CSS3** — 3D transforms, animations, responsive design  
- **JavaScript** — interactivity and controls  
- **Font Awesome** — UI icons

## 🎮 How to Explore

### 🔄 Navigation
- **Mouse:** Rotate the room by moving the cursor  
- **Click / Tap:**  
  - Open the door  
  - View certificates  
- **Keyboard Shortcuts:**  
  - `+` / `-` → Zoom  
  - `0` → Reset view  
  - `Enter` → Open door  
  - `Esc` → Close modal  

### 🧭 Room Layout
- **🚪 Back Wall:** Entrance with interactive door  
- **📚 Side Walls:** Certificate displays  
- **🪔 Floor:** Decorative rug
